# 💰 MoneyFlow - Fintech Personal Finance App

**MoneyFlow** là một ứng dụng Android quản lý tài chính cá nhân hiện đại, tập trung vào tính chính xác, bảo mật và hiệu năng. Dự án áp dụng những công nghệ Android mới nhất và kiến trúc Clean Architecture chuẩn Enterprise.

## ✨ Tính năng chính
- 📊 **Thống kê chi tiết**: Biểu đồ chi tiêu theo hạng mục.
- 📂 **Quản lý ngân sách**: Mô hình phong bì tài chính (Envelope System).
- 💾 **Sao lưu & Khôi phục**: Đảm bảo an toàn dữ liệu người dùng.
- 🎯 **Mục tiêu tiết kiệm**: Theo dõi tiến độ tích lũy.
- 🌙 **Giao diện hiện đại**: Hỗ trợ Dark Mode và Jetpack Compose.

## 🛠 Tech Stack
- **Language**: Kotlin
- **UI**: Jetpack Compose (MVI Pattern)
- **Architecture**: Clean Architecture + Feature-Based Modularization
- **Persistence**: Room Database + DataStore
- **Dependency Injection**: Hilt
- **Asynchronous**: Coroutines + Flow
